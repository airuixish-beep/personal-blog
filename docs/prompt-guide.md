# Prompt Guide

A prompt tells a language model what task to perform and provides the context needed to do it well.

## Simple structure

A useful beginner structure is:

1. **Task** — clearly state what you want.
2. **Context** — provide relevant background.
3. **Constraints** — specify format, length, audience, or boundaries.
4. **Examples** — include an example when the desired output is easier to show than describe.

## Example

```text
Task: Summarize the following paragraph.
Audience: Beginner AI students.
Length: No more than five bullet points.
Keep technical terms but explain them in plain language.
```

## Tips

- Be specific about the desired result.
- Put important constraints close to the task.
- Break complex workflows into steps.
- Evaluate outputs instead of assuming the first answer is correct.
