## Project Name
AI Lab 7 — Open Source AI API Learning Playground

## Category
Education / Open Source

## Repository
https://github.com/airuixish-beep/personal-blog

## Project Description
AI Lab 7 is a free, non-commercial, open-source educational project that helps beginners, students, and independent developers learn the fundamentals of modern AI APIs and large language models.

The project provides beginner-friendly documentation, runnable Python and JavaScript examples, prompt-engineering exercises, token/context-window explanations, API error-handling examples, and a lightweight FastAPI-based learning playground.

All core source code and educational materials are publicly available on GitHub. The project does not sell API credits, AI tokens, subscriptions, hosting, software licenses, or server resources. The goal is to provide openly accessible technical learning materials and practical demonstrations for people who are starting to learn AI application development.

The public server will be used to host the documentation and lightweight interactive learning demos so users can explore the examples without needing to configure a local development environment first.

## Technical Description
The project uses Python and FastAPI for the backend, simple HTML/JavaScript for learning interfaces, and lightweight example clients in Python and JavaScript. It is designed to run on Ubuntu Linux behind Nginx, with HTTPS enabled. Docker may be used for repeatable deployment.

The server will host documentation, public educational examples, prompt experiments, sample REST endpoints, and lightweight API demonstrations. Large language model inference will not be performed locally; demonstrations will use mock responses or external APIs when appropriate, keeping server resource requirements modest.

Requested resources:
- 2 vCPU
- 4 GB RAM
- 50 GB SSD storage
- Ubuntu 24.04 LTS
- Standard public network connectivity

This configuration is sufficient for documentation, a small FastAPI service, static learning content, and moderate educational demo traffic. No cryptocurrency mining, game server, VPN/proxy service, bulk email, paid SaaS, commercial hosting, or server-resource resale will be operated.
