# AI Lab 7 Roadmap

## Phase 1 — Foundation
- Publish beginner documentation for LLMs, tokens, context windows, prompts, and API basics.
- Provide minimal Python and JavaScript examples.
- Maintain a lightweight FastAPI demo service.

## Phase 2 — Public Learning Playground
- Add safe request/response demos using mock or user-supplied API credentials.
- Add streaming response examples.
- Add structured error-handling examples.

## Phase 3 — Model Comparison Education
- Explain differences between model families, context limits, latency, and cost concepts.
- Add reproducible prompt-comparison exercises without ranking providers commercially.

## Phase 4 — Community Learning
- Accept documentation improvements and beginner examples.
- Expand multilingual educational material.
- Keep all core learning content freely accessible.

The project remains non-commercial and open source. Server resources are intended only for educational documentation and demonstrations.
