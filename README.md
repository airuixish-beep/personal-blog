# AI Lab 7

Open-source AI API Learning Playground

AI Lab 7 is a free and open-source educational project for learning modern AI APIs, large language models (LLMs), prompt engineering, and basic AI application development.

## Mission

Our goal is to make AI API development easier to understand for beginners, students, and independent developers.

## What you can learn

- LLM basics
- Tokens and context windows
- REST API fundamentals
- Streaming responses
- Prompt engineering
- Python AI API examples
- JavaScript AI API examples
- Error handling
- Model comparison concepts

## Project structure

- `docs/` beginner-friendly learning notes
- `examples/` minimal Python and JavaScript examples
- `app/` lightweight FastAPI demo service

## Non-commercial project

AI Lab 7 is a non-commercial educational and open-source project. It does not sell AI tokens, API credits, subscriptions, hosting services, or server resources.
